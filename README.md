# programming-for-data-analytics

by Oksana Abrosimova

This repository contains a set of Jupyter Notebooks created as part of the *Programming for Data Analytics* module. The notebooks include practical assignments designed to demonstrate skills in data acquisition, cleaning, manipulation, filtering, visualization, and analytical reasoning using Python.

## Contents

| Notebook | Description |
|---------|-------------|
| assignment02-bankholidays.ipynb | List all Northern Ireland bank holidays and identify those unique to Northern Ireland compared to the rest of the UK |
| assignment03-pie.ipynb | Process a dataset of 1,000 individuals to extract email domains and create a visually appealing pie chart showing their distribution |
| assignment05-population.ipynb | Analyse differences between male and female populations in Ireland by age, calculate weighted mean ages by sex, and evaluate sex-based population gaps within a five-year age range around a selected age |
| assignment06_weather.ipynb | Retrieve hourly weather data for Knock Airport, visualise temperature trends and aggregated means by day and month, and analyse windspeed with rolling averages and daily/monthly statistics despite missing values |

### Software
