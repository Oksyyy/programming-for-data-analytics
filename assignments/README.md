# programming-for-data-analytics

by Oksana Abrosimova

This repository contains a set of Jupyter Notebooks created as part of the *Programming for Data Analytics* module. The notebooks include practical assignments designed to demonstrate skills in data acquisition, cleaning, manipulation, filtering, visualization, and analytical reasoning using Python.

## Contents

| Notebook | Description |
|---------|-------------|
| assignment02-bankholidays.ipynb | List all Northern Ireland bank holidays and identify those unique to Northern Ireland compared to the rest of the UK |
| assignment03-pie.ipynb | Process a dataset of 1,000 individuals to extract email domains and create a pie chart showing their distribution |
| assignment05-population.ipynb | Analyse age-based differences in populations in Ireland by sex, calculate weighted mean ages, and identify the biggest population difference in a selected age band |
| assignment06_weather.ipynb | Analyse hourly weather data for Knock Airport - visualise temperature trends, and explore windspeed with daily/monthly summaries and rolling averages |

## Requirements

### Software
- **Python 3.10+** — required to run the scripts and notebooks  
  Install from: https://www.python.org  
- **Jupyter Notebook** (or VS Code + Jupyter extension)  
  Installation instructions: https://jupyter.org/install

### Python Packages
All required packages are imported within each respective notebook: 
- `pandas`: enables data handling, filtering, analysis.
- `matplotlib.pyplot`: creating charts and visualisations.
- `requests`: retrieving data from API's.
